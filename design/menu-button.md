# Кнопка меню (три полоски) — согласованная спецификация

**Статус: СОГЛАСОВАНО, но НЕ РЕАЛИЗОВАНО.**
Реализовывать только по прямому указанию владельца проекта.
Без команды «делай кнопку меню» — код не менять.

Эталон: `vivaldi_qBc95h16qJ.png` (три полоски в левом верхнем углу).
Макет результата: `preview-menu-variant-b.png` (полный экран + увеличение ×3).

## Геометрия иконки (замер по эталону)

| Параметр | Значение |
|---|---|
| Полос | 3 |
| Длина полосы | 17 dp |
| Толщина полосы | 2 dp |
| Зазор между полосами | 4 dp |
| Размер блока | 17 × 14 dp |
| Скругление концов | 1 dp |
| Подложка / рамка | нет |

## Цвет

`#C4BDAD` — приглушённое золото (средний замер по эталону: R196 G189 B173).
Плюс мягкая тень (чёрная, ~25% прозрачности, смещение 1 dp) для читаемости
на светлых и на золотых участках страницы.

## Размещение (выбран вариант B)

| Параметр | Значение |
|---|---|
| Вариант | **B** |
| Отступ слева | **16 dp** |
| Отступ сверху | **18 dp** |
| Выравнивание | левый верхний угол, поверх страницы (edge-to-edge, статус-бара нет) |

Отклонённые варианты: A — 12/14 dp (слишком притык к кромке), C — 20/24 dp (глубоко в контент).

## Поведение

- **Всегда видна** (постоянное отображение), слой поверх `WebView`.
- Тач-зона **44 dp** от самого угла (0,0) с внутренним отступом 16/18 dp:
  визуально полосы в 16/18 dp, но нажимать удобно.
- Скрывать на время полноэкранного видео и пока открыт диалог пароля.
- Тап: **не согласовано** — либо «Назад», либо мини-меню («Обновить · Назад · На главную»).
  Уточнить перед реализацией. Киоск-логику не ломает: выход на другие сайты всё равно заблокирован.
