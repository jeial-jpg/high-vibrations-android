# На высоких вибрациях

Мини-браузер для одного сайта: `https://high-vibrations.ru/`.
Открывается сразу нужной страницей, во весь экран, без адресной строки и вкладок.
Внутри сайта (и всех его поддоменов) работает всё как в обычном браузере.

| | |
|---|---|
| Название | На высоких вибрациях |
| Пакет | `ru.highvibrations.browser` |

## Настройки

Единственный файл для правки — `app/src/main/res/values/config.xml`:

| Параметр | Смысл |
|---|---|
| `start_url` | адрес, который открывается при запуске |
| `allow_subdomains` | `true` — поддомены разрешены |
| `lock_to_site` | `true` — уйти на другой сайт нельзя |
| `extra_allowed_hosts` | дополнительные домены (оплата, OAuth), обычно пусто |

## Сборка

```
BUILD-HIGH-VIBRATIONS.bat          :: debug APK -> app\build\outputs\apk\debug\app-debug.apk
BUILD-HIGH-VIBRATIONS.bat install  :: собрать, поставить и запустить (BlueStacks/телефон)
BUILD-HIGH-VIBRATIONS.bat clean    :: очистка
```

Только локальные JDK 17, Android SDK 34, Gradle 8.11.1, AGP 8.6.1. Скачиваний нет.

## Поведение сессии

| Ситуация | Результат |
|---|---|
| Свернули и вернулись (процесс жив) | страница и история сохраняются, перезагрузки нет |
| Android выгрузил приложение из кеша | открывается `start_url` заново |
| Поворот экрана | Activity не пересоздаётся, страница не перезагружается |

## Уведомления

| Версия Android | Что делает приложение |
|---|---|
| 13+ (API 33+) | системный запрос «Разрешить уведомления?» при первом запуске |
| 8–12 | канал уведомлений создаётся сам; если выключено — предложение открыть настройки |
| 7 и ниже | разрешение выдаётся при установке |

Факт запроса сохраняется в `shared_prefs/app_state.xml` (`notification_permission_asked`),
поэтому повторно приложение не спрашивает и выбор пользователя не сбрасывается.

Уведомления, которые показывает сама страница (`new Notification(...)`), выводятся как
системные через мост `HVNotify`.

> Ограничение: WebView не поддерживает Push API / Service Worker push, поэтому
> уведомления, приходящие с сервера при закрытом браузере, невозможны без FCM.

## Структура кода

Один файл — одна ответственность, не больше 250 строк:

```
app/src/main/java/ru/highvibrations/browser/
  MainActivity.java        точка входа: UI, жизненный цикл, «назад», выбор файла
  KioskConfig.java         чтение и нормализация res/values/config.xml
  SitePolicy.java          правило «можно ли грузить этот URL»
  KioskWebViewClient.java  сторож навигации: чужие домены, редиректы, SSL
  KioskChromeClient.java   полноэкранное видео, камера/микрофон, выбор файлов
  FullscreenController.java  полноэкранный режим

app/src/main/res/
  values/config.xml        адрес сайта и правила
  values/strings.xml       название приложения
  drawable/ic_launcher.xml иконка
```

## Правило для новых функций

Новая функция = новый класс рядом с существующими + вызов из `MainActivity`.
`MainActivity` не разрастается: только сборка UI и проксирование событий.
Каждый файл держим ≤ 250 строк.
